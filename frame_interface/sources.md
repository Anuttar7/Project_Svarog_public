# Frame Interface: Citations & Evidence Sources

1. **Svarog CAD Workshop Reference Deliverables (`icss-briefs/drafts/svarog-1u-reference/`)**
   - Fusion 360 models, reference STEP export (`atrium_1u_reference.step`), and FEA verification results under 10g and 20g static equivalents.

2. **CubeSat Design Specification (CDS) REV 14.1, Cal Poly SLO**
   - Standards for CubeSat exterior envelope, corner rail widths (minimum 8.5 mm), contact pad geometry, and transverse face apertures.

3. **REXUS User Manual (RX_UserManual_v7-17_26Nov21)**
   - Payload structural mechanical interface rules, fastener torque standards, and launch vehicle interface coordinate frames.

4. **Thomas's Obsidian Vault Reference: `Atlas/Projects/Svarog/Repo-Map.md`**
   - System interface mapping and identification of frame interface requirements.
